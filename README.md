# emiss_download — CLI для загрузки данных ЕМИСС

Консольная утилита для выгрузки статистических данных с портала
[fedstat.ru](https://fedstat.ru) (ЕМИСС) через R-пакет
[fedstatAPIr](https://github.com/DenchPokepon/fedstatAPIr).

Используется для автоматической выгрузки данных с fedstat.ru (ЕМИСС) в CSV. Вместо ручной работы с интерфейсом портала: выбираете индикатор и фильтры в браузерном конфигураторе, запускаете одну команду — получаете файл в длинном формате, готовый к открытию в Excel, pandas или R. Подходит как для разовых выгрузок, так и для интеграции в скрипты и автоматизированные пайплайны.

Является частью инструментария `loademiss`:

```
emiss-configurator.html   — браузерный UI для настройки фильтров и генерации конфига
emiss_proxy.py            — локальный HTTP-прокси: запускает R, отдаёт данные конфигуратору
emiss_download.py         — этот файл: CLI для пакетной/скриптовой выгрузки
```

> [!WARNING]
> **Не запускайте конфиги из непроверенных источников.**
> Конфиг-файл (`.json`) передаётся напрямую в R-код без полной санации.
> Вредоносный конфиг может содержать значения фильтров, ломающие экранирование,
> и выполнить произвольный R-код на вашей машине.
> Используйте только конфиги, которые сгенерировали сами через `emiss-configurator.html`.

## Требования

| Компонент | Минимальная версия | Назначение |
|---|---|---|
| Python | 3.10+ | запуск скрипта |
| R | 4.0+ | обращение к API ЕМИСС |
| fedstatAPIr | актуальная | R-пакет для работы с fedstat.ru |
| data.table | актуальная | быстрая обработка данных в R |
| jsonlite | актуальная | передача конфига между Python и R |

Python-зависимости отсутствуют — скрипт использует только стандартную
библиотеку (`argparse`, `json`, `subprocess`, `tempfile`, `pathlib`).

```cmd
R --version
```

Если команда не найдена — R установлен, но его папка не добавлена в PATH.
Это решается вручную:

**Шаг 1.** Найдите папку с R (обычно `C:\Program Files\R\R-4.x.x\bin`):

```cmd
where /r "C:\Program Files" Rscript.exe
```

**Шаг 2.** Откройте настройки: `Win+R` → введите `sysdm.cpl` → вкладка **«Дополнительно»** → **«Переменные среды»**.

**Шаг 3.** В блоке **«Системные переменные»** выберите **Path** → **«Изменить»** → **«Создать»** → вставьте путь к папке `bin` (например, `C:\Program Files\R\R-4.4.1\bin`).

**Шаг 4.** Нажмите ОК во всех окнах, **откройте новое окно** CMD или PowerShell и повторите проверку.

</details>

## Конфиг. Быстрое создание

Конфиг можно составить двумя способами.

### Способ 1 — визуальный конфигуратор (рекомендуется)

В комплекте идут два файла:

```
emiss_proxy.py            — локальный HTTP-сервер на порту 8765
emiss-configurator.html   — браузерный UI (открывается автоматически)
```

**Шаг 1.** Запустите прокси:

```bash
python3 emiss_proxy.py
```

Браузер откроется автоматически на `http://127.0.0.1:8765/`.
Если не открылся — перейдите по адресу вручную.

**Шаг 2.** Введите ID индикатора в поле поиска и нажмите **Загрузить**.
Прокси вызовет R, получит список всех полей и значений, отобразит карточки фильтров.

**Шаг 3.** Настройте фильтры:
- По умолчанию все значения выбраны (`*`).
- Снимите галочки с ненужных, или воспользуйтесь поиском внутри карточки.
- Укажите диапазон лет в блоке **Период**.

**Шаг 4.** Нажмите **Сохранить конфиг** — файл `config_<ID>.json` сохранится
рядом с `emiss_proxy.py`. Этот файл передаётся напрямую в `emiss_download.py`.

```
                    ┌─────────────────────────────┐
                    │   emiss-configurator.html   │  ← браузер
                    └──────────┬──────────────────┘
                               │ HTTP
                    ┌──────────▼──────────────────┐
                    │      emiss_proxy.py          │  ← localhost:8765
                    └──────────┬──────────────────┘
                               │ Rscript
                    ┌──────────▼──────────────────┐
                    │     fedstat_get_data_ids()   │  ← R / fedstatAPIr
                    └─────────────────────────────┘
```

> **Примечание.** Прокси работает только локально — никакие данные
> не отправляются на внешние серверы кроме `fedstat.ru`.

---

### Способ 2 — вручную

Запустите `--list-filters` чтобы увидеть точные названия полей и значений,
затем напишите JSON по шаблону из раздела [Формат конфига](#формат-конфига).

```bash
python3 emiss_download.py 62309 --list-filters
```

## Формат конфига

Конфиг — это JSON-файл, описывающий **что и за какой период скачать**.
Генерируется автоматически в `emiss-configurator.html`, но можно написать
вручную.

```json
{
  "indicator_id": "62309",
  "period": {
    "year_from": 2024,
    "year_to": 2026
  },
  "filters": {
    "Показатель": {
      "selected": ["*"]
    },
    "Единица измерения": {
      "selected": ["*"]
    },
    "ОКАТО (межведомственный)": {
      "selected": ["*"]
    },
    "видам продукции": {
      "selected": [
        "Алкогольная продукция (без пива, напитков, изготовляемых на основе пива, сидра, пуаре и медовухи) - всего",
        "Спиртные напитки свыше 9% - всего"
      ]
    }
  }
}
```

### Поля конфига

| Поле | Тип | Описание |
|---|---|---|
| `indicator_id` | строка | ID индикатора на fedstat.ru |
| `period.year_from` | число | Первый год периода (включительно) |
| `period.year_to` | число или `"today"` | Последний год; `"today"` = текущий год |
| `filters` | объект | Словарь `"Название поля": { "selected": [...] }` |
| `filters.*.selected` | массив строк | Список значений; `["*"]` = все значения |

### Правила фильтров

- **Ключи фильтров** — точные названия полей из `--list-filters` (с сохранением
  регистра и пробелов).
- **Поле «Год»** в `filters` можно не указывать — оно управляется через `period`
  автоматически. Если всё же указано — будет проигнорировано с предупреждением.
- Значение `["*"]` означает «взять все доступные значения поля» — эквивалент
  отсутствия фильтра.
- Если указанное значение отсутствует в данных — скрипт предупредит и заменит
  его на `"*"` (не упадёт с ошибкой).

## Использование

### Просмотр фильтров

Перед составлением конфига полезно узнать, какие поля и значения
доступны для индикатора:

```bash
python3 emiss_download.py 62309 --list-filters
```

или короткий флаг:

```bash
python3 emiss_download.py 62309 -l
```

Вывод покажет все поля и до 30 значений в каждом. Названия полей и значений
нужно копировать **дословно** в конфиг.

---

### Загрузка данных

#### Базовый вызов

```bash
python3 emiss_download.py 62309 config_62309.json
```

Файл будет сохранён как `emiss_62309_20260607_035400.csv`
(имя включает ID индикатора и временну́ю метку).

#### С явным именем выходного файла

```bash
python3 emiss_download.py 62309 config_62309.json --output alcohol_2024_2026.csv
```

или короткий флаг:

```bash
python3 emiss_download.py 62309 config_62309.json -o alcohol_2024_2026.csv
```

#### Конфиг без указания indicator_id в аргументах

Если в конфиге уже есть `indicator_id`, его необязательно повторять:

```bash
python3 emiss_download.py "" config_62309.json
```

Хотя для ясности рекомендуется передавать ID явно.

---

### Все аргументы

```
python3 emiss_download.py [-h] [-l] [-o OUTPUT] indicator [config]

Позиционные аргументы:
  indicator            ID индикатора ЕМИСС (например 62309)
  config               Путь к JSON-конфигу (из emiss-configurator)

Опциональные аргументы:
  -h, --help           показать справку
  -l, --list-filters   показать все доступные фильтры индикатора
  -o, --output FILE    имя выходного CSV-файла
```

### Значение меток в логах

| Метка | Значение |
|---|---|
| `[INFO]` | Информация от Python-оболочки перед запуском R |
| `[R]` | Прогресс выполнения R-кода |

| `[OK]` | Финальное подтверждение от Python; файл создан |

## Структура CSV

Выходной CSV содержит данные в «длинном» формате. Типичные колонки:

| Колонка | Пример | Описание |
|---|---|---|
| `indicator_id` | `62309` | ID индикатора |
| `period_id` | `2024` | Год наблюдения |
| `value` | `1234.56` | Числовое значение |
| `unit` | `тыс. декалитров` | Единица измерения |
| `okato_name` | `Российская Федерация` | Регион |
| `indicator_name` | `Розничная продажа...` | Название показателя |
| *прочие поля* | | Зависят от индикатора |

Файл сохраняется с **BOM (UTF-8 with BOM)** — это обеспечивает корректное
открытие в Microsoft Excel без ручного выбора кодировки.

## Типичные ошибки

### `Rscript не найден`

```
[ERROR] Rscript не найден. Установите R:
  sudo apt install r-base
```

**Решение:** установите R как описано в разделе [Установка R](#1-r-и-r-пакеты).

---

### `Error in library(fedstatAPIr) : there is no package called 'fedstatAPIr'`

**Решение:** установите R-пакеты:

```bash
Rscript -e 'install.packages(c("fedstatAPIr","data.table","jsonlite"), repos="https://cloud.r-project.org")'
```

---

### `[WARN] Поле 'X' не найдено в data_ids, пропускаем`

Название поля в конфиге не совпадает с реальным названием в данных.

**Решение:** запустите `--list-filters` и скопируйте точное название поля.

---

### `[WARN] Ни один год из [2026] не найден в [2020, 2021, 2022, 2023], берём все`

ЕМИСС ещё не опубликовал данные за запрошенный год.

**Решение:** уменьшите `year_to` до последнего доступного года или оставьте
предупреждение — скрипт автоматически возьмёт все доступные годы.

---

### `[ERROR] R завис (timeout 300s)`

R не ответил в течение 5 минут. Обычно это проблема с сетью или перегрузкой API.

**Решение:** повторите попытку. Если проблема постоянная — проверьте
доступность `fedstat.ru`.

### Пакетная загрузка нескольких индикаторов (bash)

```bash
for id in 62309 57609 38441; do
  python3 emiss_download.py $id config_$id.json -o data_$id.csv
done
```

### Интеграция с cron для ежемесячного обновления

```cron
# Каждый 1-й день месяца в 03:00
0 3 1 * * cd /home/user/emiss && python3 emiss_download.py 62309 config_62309.json -o data/62309_$(date +\%Y\%m).csv >> logs/emiss.log 2>&1
```
